# ⚠️ ТРЕБУЕТСЯ JAVA 21 ДЛЯ MINECRAFT И AUTH-КЛЮЧ ДЛЯ BEAMMP
По вопросам discord @awarmx

Запуск Minecraft и BeamMP серверов в 1 клик.

1. Мониторинг CPU, RAM и игроков.
2. Отправка команд с подсказками по /.
3. Для BeamMP нужен свой AUTH-ключ.
4. Если start.bat не работает — укажи путь к BeamMP-Server.exe в настройках.
5. С локального ПК — localhost.
6. Для других игроков — открыть порты на роутере или использовать VPN (Radmin).
