# server-side-control-application-BETA
 Запуск Minecraft и BeamMP серверов в 1 клик.  1Мониторинг CPU, RAM и игроков.  2Отправка команд с подсказками по /.  3Для BeamMP нужен свой AUTH-ключ.  4Если start.bat не работает — укажи путь к BeamMP-Server.exe в настройках.  5С локального ПК — localhost.  6Для других игроков — открыть порты на роутере или использовать VPN (*Radmin*).
